# Aferiy Powerstation App

Minimal Expo + Tamagui frontend with a Node server backend.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the server:
   ```bash
   npm run server
   ```
3. Start the app for web:
   ```bash
   npm run web
   ```

## Notes

- Web runs at `http://localhost:19006` by default.
- API server runs at `http://localhost:3333`.
- The frontend fetches `/api/status` from the server.
